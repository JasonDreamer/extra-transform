# 仕組み

[English](how-it-works.md) | 日本語

## 合成

レイヤーの値はドライバーで標準の Delta（`delta_location` など）に流し込んでいます。最終的な行列は Blender がいつもどおり Delta から計算するので、レイヤー1枚なら標準の Delta と結果は同じです。

複数枚のときの合成:

| チャンネル | 合成 |
| --- | --- |
| 位置 | 足し算 |
| スケール | 軸ごとの掛け算 |
| 回転 | 回転行列の掛け算（クォータニオンモードではクォータニオン）。後のレイヤーが外側（左）から掛かる |

チャンネルは別々に合成するので、外側のレイヤーで回転させても内側のレイヤーの位置は回りません。Empty を親子にして重ねたときとはここで結果が変わります。

回転はオブジェクトの回転モードで扱い、モードを変えるとドライバーを作り直します。軸角度モードは Delta に回転がないので、位置とスケールだけ合成します。

## 値の保存先

レイヤーの値はオブジェクトのカスタムプロパティに `Extra 1 Location`、`Extra 2 Euler Rotation` のような名前で入っています。数字はスタックの何番目かで、並べ替えるとプロパティ名もキーフレームのパスも付け直します。

アドオンのプロパティ（`bpy.props`）に置かないのは、ドライバーから読むと依存関係がループするためです。

## ドライバー

ドライバーはすべて、レイヤーの値を読んで Delta に書くだけの1段構成です。ドライバーの出力を別のドライバーで読む形にすると、Blender 5.2 のマルチスレッド評価でカスタムプロパティへの書き込みがたまに抜けるので、避けています。

- 位置: SUM ドライバー
- スケール: `a*b*c...` の式。レイヤー数の上限 100 はこの式の長さの制限から来ています
- 回転（1枚）: 入力をそのまま渡します
- 回転（2枚以上）: アドオンが `bpy.app.driver_namespace` に登録する `extra_transform_rotation` 関数で計算します

この関数はアドオンが無いと存在しないので、回転レイヤーが2枚以上あるファイルをアドオン無しで開くと回転がずれます。位置とスケールはアドオン無しでもそのまま動きます。

## Ctrl+A などの標準操作

Ctrl+A、Alt+G/R/S、「トランスフォームをデルタに」は Delta に直接書き込むので、何もしなければ次の評価でドライバーに上書きされます。そこで評価のたびに Delta の値を控えておき、次の評価までに変わっていれば、その差をレイヤーに書き戻しています。

0（スケールは 1）が書かれたチャンネルは、全レイヤーのそのチャンネルを 0 に戻します。それ以外の値は、内側のレイヤーの分を差し引いて一番外側のレイヤーに入れます。

アンドゥやファイルを開いたときは、控えた値を捨てます。

## もともと Delta に値があった場合

Delta に値・アニメーション・ドライバーがあるオブジェクトにレイヤーを追加すると、それらは「Delta」という名前の1枚目のレイヤーに移ります。
