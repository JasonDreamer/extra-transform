# 仕組み

[English](how-it-works.md) | 日本語

## 1. 概要

各レイヤーの値をドライバー経由で Blender の Delta トランスフォーム（`delta_location` など）に集約する仕組みです。レイヤーが1枚の場合、計算結果は Blender 標準の Delta と同一です。

## 2. 合成ルール

各チャンネルは独立して合成されます。外側（上位）のレイヤーで回転を行っても内側（下位）のレイヤーの位置には影響しません（Empty の親子構造とは異なります）。

| チャンネル | 合成方法 | 備考 |
| --- | --- | --- |
| 位置 | 加算 | |
| スケール | 乗算 | 軸ごとに計算 |
| 回転 | 行列（またはクォータニオン）の乗算 | 外側のレイヤーが左から掛かる |

各レイヤーの影響力（Influence, 0〜1）は、合成の前にレイヤーの値を初期値（位置 0、回転 0、スケール 1）から線形に寄せます。NLA ストリップの影響力（Replace モード）と同じ考え方です。

| チャンネル | 影響力 w のときの値 |
| --- | --- |
| 位置 | 値 × w |
| スケール | 1 − w + 値 × w |
| Euler 回転 | 各角度 × w |
| クォータニオン回転 | (1 − w + W × w, X × w, Y × w, Z × w) を正規化 |

影響力 1 のときは、影響力の無い場合と結果が完全に一致します。

- **回転モード**: オブジェクトの回転モードに従います。モード変更時はドライバーを再生成します。
- **軸角度 (Axis-Angle)**: Delta に回転の対応がないため、位置とスケールのみ合成します。

## 3. データの保存構造

- レイヤーの値はオブジェクトのカスタムプロパティ（例: `Extra 1 Location`、`Extra 1 Influence`）に保存されます。
- 番号はスタック順に対応し、並べ替えるとプロパティ名とキーフレームのパスを再割り当てします。
- `bpy.props` を使用しない理由は、ドライバー参照時の評価ループ（循環依存）を防ぐためです。

## 4. ドライバー仕様とマルチスレッド対策

すべてのドライバーは 1 段構成（レイヤー値を直参照して Delta へ直接出力）の単純な数式です。Python の式を使わないので、Python の自動実行がオフでも警告は出ません。多段構成にすると、Blender 5.2 のマルチスレッド評価で書き込み漏れが発生します。

- **位置**: `a*A+b*B+...` の式（小文字が値、大文字が影響力）
- **スケール**: `(1-A+a*A)*(1-B+b*B)*...` の式（レイヤー上限 20 は数式文字列の長さ制限による）
- **回転（1枚）**: `a*A` の式（クォータニオンの W 成分は `1-A+a*A`）
- **回転（2枚以上）**: 単純な数式に収まらないため、ドライバーは使わずアドオンのハンドラーが計算して Delta に直接書き込む

2枚以上の回転は、レイヤーの値が変わったときと、フレームが変わる直前（再生、レンダリング、モーションブラーの途中のフレームを含む）に計算します。キーフレームはそのフレームの値を F-Curve から読みます。NLA ストリップや、レイヤーの値に付けたドライバーは F-Curve から読めないため、1フレーム遅れるか反映されません。

## 5. 標準操作（Ctrl+A / Alt+G, R, S）への追従

標準のトランスフォーム操作は Delta へ直接書かれるため、以下の処理で各レイヤーへ書き戻します。

1. 毎評価時に Delta の値をキャッシュし、変更を検出。
2. クリア（0 / スケール 1）されたチャンネルは、全レイヤーの値を初期化。
3. それ以外の変更は、内側レイヤーの値を差し引いた値で、影響力が 0 でない一番外側のレイヤーを置き換え。
4. Undo 時およびファイル読み込み時は、キャッシュをリセット。

## 6. 注意事項

- **既存 Delta 値の扱い**: Delta に値・アニメーション・ドライバーが存在する状態で追加した場合、既存データは自動生成される「Delta」レイヤーへ移動します。
- **アドオン未導入時の挙動**:
  - 位置・スケール: 正常に動作します。
  - 回転（2枚以上）: 保存したときの値で止まり、アニメーションしません。
- **1.0.x で作ったレイヤー**: 影響力のプロパティが無いため、開いたときに影響力 1 で追加されます。
- **1.0.0 で保存したファイル**: 回転のドライバーに Python の関数を使っていたため、開くと警告が出ます。アドオンを入れて開くとドライバーが置き換わり、保存し直せば以降は警告が出ません。
