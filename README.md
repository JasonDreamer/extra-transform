# Extra Transform

Delta Transform をオブジェクトに何層でも重ねる Blender アドオン。Blender 5.2 以降。

## インストール

Releases の zip を、プリファレンス > エクステンションを入手 > ▾ > ディスクからインストール で入れる。

## 使い方

オブジェクトプロパティ > トランスフォーム > デルタトランスフォーム の Add Transform でレイヤーを追加する。後から足したレイヤーほど外側にかかる。

回転レイヤーが2枚以上あるファイルは、アドオンを入れていないと回転が正しく出ない。
